FLC 启动器 v2.1.0 · Windows x64
================================

运行方法
--------
1. 把整个「FLC启动器」文件夹解压到任意位置（建议放在用户目录下，
   例如 D:\Games\FLC启动器）。
2. 双击文件夹里的 FLC启动器.exe。

重要：不要把 FLC启动器.exe 单独拷出来运行。
      程序依赖同级 _internal 文件夹里的 Python 运行时，
      缺少该文件夹会导致无法启动。

请不要放进 C:\Program Files 等受保护目录
----------------------------------------
启动器需要在自身目录下写入 config.json 并下载游戏文件。
受保护目录会导致写入失败。放在用户目录下才能正常使用。

首次启动
--------
- 会在同目录自动生成 config.json（本压缩包内不含该文件，首次运行自动创建）
- 会自动建立 .minecraft 游戏目录
- 到「下载」页选一个版本安装，然后回「启动」页点「开始游戏」
- Java 会由启动器自动检测；若缺失，到「设置 → Java 管理」点「自动下载」

系统要求
--------
- Windows 10 / 11（64 位）
- 不需要预装 Python（已内置）
- 不需要管理员权限
- 不需要注册表写入；删除整个文件夹即彻底卸载

关于 Windows SmartScreen
------------------------
本程序未做代码签名，首次运行时 Windows 可能提示「已保护你的电脑」。
点「更多信息」→「仍要运行」即可。这是未签名程序的常规提示。
