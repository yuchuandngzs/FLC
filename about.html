关于

FLC 启动器是一个免费开源的 Minecraft 启动器。

技术

Python + Tkinter 编写，界面纯代码绘制（无边框窗口、自绘控件），不使用图片素材。PyInstaller 打包为绿色版。

致谢

  • BMCLAPI — 国内下载镜像
  • Modrinth — 资源数据
  • Fabric MC
  • Eclipse Adoptium — Java 运行时
  • PCL2 — 启动流程参考

常见问题

Q：支持 Linux / macOS 吗？
A：目前仅 Windows。

Q：会被盗号吗？
A：微软登录走官方设备代码流程，令牌只保存在本地配置文件。

Q：报毒怎么办？
A：PyInstaller 打包的程序偶有误报，添加信任即可。源码可自行审计。
