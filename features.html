功能

下面是启动器实际有的功能。

下载

  • 原版正式版 / 快照版，列表带版本号与更新时间
  • 32 线程并发，BMCLAPI 国内镜像，断点续传
  • 支持多选批量安装

加载器

  • Forge / NeoForge / Fabric / OptiFine / LiteLoader
  • 下载流程里直接选，一步装完
  • 自动解析依赖、补全库文件

资源中心

  • Modrinth 模组 / 光影 / 材质包搜索
  • 按当前 MC 版本过滤
  • 一键下载，自动落到对应目录

启动

  • Java 自动检测，缺失可一键下载运行时
  • 内存 512–32768 MB 可调
  • 离线账户免注册，微软账户设备代码登录

版本管理

  • 已安装版本一屏看清，双击即启动
  • 版本隔离：各版本独立存档与模组目录
  • 删除 / 打开目录 / 刷新

界面

  • 无边框窗口，纯代码绘制，无图片素材
  • 深色 / 浅色双主题，可跟随系统
  • 绿色免安装，删文件夹即卸载
